Rethinking the CISA BOD 26-04 Directive in the Age of Frontier AI Models

Frontier models have crossed a line that changes the math of vulnerability research. Mythos class systems now discover zero days at machine speed, surfacing flaws in code that survived years of expert review. In a single evaluation run, a frontier model found hundreds of vulnerabilities in a widely used codebase, built scores of working exploits, and uncovered a remote code execution flaw, more than a decade old, granting root to unauthenticated attackers. Over 99 percent of those discoveries remain unpatched. This is the vulnpocalypse made manifest, and it is no longer a forecast.

Finding flaws at scale is only good news if the world can fix them at the same speed, and it cannot. Vendor cycles run on weeks. Enterprise deployment runs slower, blocked by operational constraints, legacy systems that cannot be touched, and change freeze periods that lock environments for weeks. When discovery accelerates and remediation does not, the gap becomes pure attack surface. CISA BOD 26-04 started the clock on risk, which is right. But every path it draws still ends in a patch. So we add the question the directive assumes away. On every Total and Partial branch, does a patch exist in time? Yes keeps CISA's timeline. No routes to the off-ramp, where the risk is closed by decision, not repair.
